WakeCraft Manager — Privacy Policy

Effective date: November 13, 2026

WakeCraft Manager is a private, noncommercial Discord administration utility for the World of WakeCraft guild server. The guild administrator operates it through a local Python setup utility, not a hosted 24/7 service.

Information accessed

When the administrator runs the utility, it accesses the Discord server name and ID, existing channel and role names and IDs, bot identity, and a limited recent message history (up to 100 messages) in designated guide channels to avoid posting duplicate bot guides. The script may temporarily process text from these messages while looking for an existing guide. It does not intentionally retain those message bodies in the local report. When scheduled events are created, it also processes the event title, description, times and selected voice channel.

How information is used

Information is used solely to inventory the server, create or update guild categories, channels, roles, permission settings and guide messages, and create scheduled events the administrator explicitly requests. Discord processes the resulting data under Discord's own privacy policy.

Storage and retention

The one-time setup utility writes a local setup-report.json containing the server ID, execution time, changes made, and warnings or errors. It is stored on the administrator's computer; the utility does not upload this report to a separate hosting service. Discord stores guild channels, roles, guides and scheduled events according to its own service rules. The administrator can delete the local report when no longer needed.

What the utility does not do

The current setup utility does not read private messages, record voice conversations, run continuous user tracking, or sell member information. It does not independently grant roles to guild members. Future features may need a revised policy before being enabled.

Access, removal and questions

Guild members may contact the World of WakeCraft server owner or an officer to ask questions about bot use or to request removal of content the bot posted. A server administrator can remove the bot from the server or remove affected messages through Discord. Requests to review or delete the local setup report should be sent to the administrator. Discord-account data requests can be made to Discord separately.

WakeCraft Manager is an independently operated guild tool and is not affiliated with or endorsed by Blizzard Entertainment or Discord.
